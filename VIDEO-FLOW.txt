2. Log in and show the desktop briefly.
3. Open Terminal.
4. Run:
   chmod +x install.sh
   sudo ./install.sh
5. Explain:
   - SSH = manage it from another PC.
   - Docker = run the server apps cleanly.
   - Sleep is disabled because this is now a server.
6. Choose Recommended starter stack.
7. Show the IP address and URLs.
8. Move to Windows.
9. Open Windows Terminal:
   ssh username@SERVER-IP
10. Open the installed apps in a browser.
11. Do not configure every app in detail.
